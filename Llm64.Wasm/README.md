# Llm64.Wasm

Blazor WASM application. Runs entirely in browser, no server processing.

**Core files:**
- `Services/PngTool.cs` - PNG manipulation logic
- `Pages/Index.razor` - Interactive UI component
- `wwwroot/index.html`, `wwwroot/about.html` - Static pages

## Run

```bash
dotnet run
# or
dotnet watch
```
